# videobelajar

## Description

A video-based learning platform designed to provide an engaging and effective learning experience through interactive educational videos.

## Features

- Homepage
- Login
- Registration
- Educational video collection
- Newsletter subscription
- Simple interactions using JavaScript

## Technologies

- HTML
- CSS
- JavaScript

## Project Structure

Main project folders:

- `pages/` → Login and registration pages
- `components/` → Reusable UI components such as navbar and footer
- `styles/` → CSS files
- `scripts/` → JavaScript files
- `assets/` → Images, icons, and other assets
